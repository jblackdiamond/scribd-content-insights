# Scribd Content Insights (synthetic take-home exercise)

A constrained conversational analytics MVP built with Streamlit. Every numerical answer is derived from certified CSV references and deterministic Python code, not generated by an LLM.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Create a GitHub repository containing `app.py`, `requirements.txt`, and `data/` and deploy with [Streamlit Community Cloud](https://share.streamlit.io/), selecting `app.py` as entrypoint.

## Optional LLM

Add `OPENAI_API_KEY` as a secret in Streamlit Cloud deployment settings to enable LLM intent classification. Without it, deterministic keyword routing still works. Never commit an API key to GitHub.

## Architecture

User question → (optional) LLM intent classification → allowlisted intent → deterministic certified CSV lookup / arithmetic → grounded answer, caveats, technical details. Unsupported questions do not produce metrics.

## Limitations

Reference-driven prototype, not a production API. No authenticated user or role permissions, live query engine, automatic dataset refresh, verified text-to-SQL, or enforced metric policy service. Certified data are synthetic interview data, not real Scribd performance. The language-model routing may be imperfect; an enterprise system should validate requested dimensions, dates, and returned values before display.
